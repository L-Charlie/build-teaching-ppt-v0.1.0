# Build Teaching Decks

`build-teaching-decks` 是一个面向教学 PPT 的 Agent Skill，用于从教案、教材、课程大纲、参考模板或已有 PPT 中，规划、生成、延续和检查教学课件。

当前版本：**v0.1.0**

## 核心特点

- 不只生成单份 PPT，也可维护同一课程的系列课件；
- 从参考 PPT 提取可复用的设计规范，而不是照着原页码逐页换字；
- 使用 `spec_lock` 固定系列配色、字体、网格与页面类型规则；
- 将系列设计规则与本章内容、页序和教学节奏分开保存；
- 在交付前进行模板审计、PPTX/SVG 结构校验与视觉检查。

## 安装与调用

将 [`skill/build-teaching-decks`](skill/build-teaching-decks) 整个目录复制到所使用 Agent 宿主的技能目录，并按该宿主的说明启用技能。调用名称为：

```text
$build-teaching-decks
```

如果使用发布包，请下载 `build-teaching-decks-skill-v0.1.0.zip`；它只包含可安装的技能目录。

## 最简示例

```text
使用 $build-teaching-decks，根据我上传的教案生成约 30 页教学 PPT。
面向高职一年级学生；保留专业术语，并逐页检查排版可读性。
```

使用模板时：

```text
使用 $build-teaching-decks，根据新材料和参考 PPT 生成教学课件。
保留模板的设计语言，但重新规划本次课程的教学顺序和页面节奏。
```

完整使用方式见 [使用指南](docs/使用指南.md)。

## 兼容性说明

本项目自带的规划、模板审计、系列管理和校验脚本只使用 Python 标准库。最终是否能生成可编辑 PPTX，取决于使用者所在的 Agent 宿主是否提供可编辑的 PPTX 生成后端。

- 有原生 PPTX 生成能力：可生成可编辑 PPTX；
- 有 SVG 转 PPTX 后端：可按后端能力生成可编辑 PPTX；
- 只有图片导出：可能得到不可编辑的图片型页面；
- 没有演示文稿后端：仍可完成教学规划、模板审计和文件校验，但不能承诺最终 PPTX。

`Presentations` 与 `PPT Master` 是可选的宿主或导出后端，不属于本项目，也不会因安装本技能自动获得。
