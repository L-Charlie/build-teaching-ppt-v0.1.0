# Contributing

Thank you for improving Build Teaching Decks.

## Before opening an issue

- Remove confidential teaching material, learner data, and copyrighted templates.
- State the host agent, operating system, Python version, and selected export backend.
- Include the smallest reproducible input and the exact command or prompt.

## Pull requests

1. Keep changes scoped to one workflow, script, or documentation improvement.
2. Preserve the distinction between series-wide `spec_lock` rules and deck-specific plans.
3. Do not add non-redistributable fonts, templates, images, or course material.
4. Run the relevant checks from the skill directory before requesting review.
5. Describe host-specific assumptions and any output/editability limitation.

## Versioning

Use semantic versions. Breaking changes to the skill layout, required inputs, or `spec_lock` format require a major-version increase.
