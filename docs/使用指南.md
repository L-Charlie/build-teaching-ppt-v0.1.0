# Build Teaching Decks 使用指南（v0.1.0）

本指南面向安装了 `build-teaching-decks` 的 Agent 宿主。它只说明如何使用技能；最终 PPTX 的可编辑性取决于宿主提供的演示文稿生成后端。

## 先确定输出文件数量

章节数量不等于 PPT 文件数量。两章合在一个 PPT 时，请明确要求使用章节页分隔；需要分别生成时，请明确要求生成两份同系列课件。

## 最低输入

至少提供一项实际教学材料：教案、教材节选、课程大纲、讲义、已有 PPT、Markdown、DOCX、PDF，或直接粘贴的教学内容。若有参考 PPT，请优先上传原始 `.pptx`，而不是截图。

## 常用请求

### 从零生成

```text
使用 $build-teaching-decks，根据上传的教案和教材生成一份教学 PPT。
面向高职一年级学生，约 35 页；保留专业术语，优先使用教材中的图片。
```

### 先确认逐页大纲

```text
使用 $build-teaching-decks，先根据教案和教材生成逐页 PPT 大纲。
标明每页教学目的、核心内容、建议视觉形式和材料来源；暂时不要生成 PPT 文件。
```

### 使用参考模板

```text
使用 $build-teaching-decks，根据新内容和参考 PPT 生成教学课件。
模板只提供设计语言；新材料决定内容和教学结构。不要按参考 PPT 页码逐页复制。
```

### 延续系列课件

```text
上一份 PPT 是本课程系列的第一份。请根据新内容生成第二份，
继续使用已有模板和 spec_lock，但重新规划本次教学结构和页面节奏。
```

## spec_lock

`spec_lock` 是系列共用的设计契约，保存画布比例、配色、字体层级、网格、页眉页脚和页面类型规则。它不应固定当前 PPT 的页数、具体内容、页面顺序或模板对应页码。

## 系列项目结构

```text
<课程系列>/
├── series/
│   ├── spec_lock.md
│   └── template/
└── decks/
    ├── 第一份PPT/
    │   ├── sources/
    │   ├── analysis/
    │   └── exports/
    └── 第二份PPT/
```

同系列应保持设计语言一致，但不应强制拥有相同页数、内容顺序或页面组合。

## 交付前检查

- 逐页渲染检查文字溢出、字体替换、对齐、图表和图片清晰度；
- 核对公式、单位、图示方向、专业术语和来源；
- 确认复杂动画、宏、嵌入对象和特殊插件元素是否仍可编辑；
- 长课件先规划全稿，再分批制作和合并。

## 已知边界

- 截图只能提供视觉参考，无法保证母版、字体、动画和可编辑结构的保留；
- 字体缺失会改变换行和排版；
- 内容过多时应拆页或增加页数，而不是无限缩小字号；
- 教材插图、模板和外部图片的公开使用需要自行确认授权。
