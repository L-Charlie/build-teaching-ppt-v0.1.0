# Build PPT Series 使用指南

本指南面向已安装 `build-ppt-series` 的 Agent 宿主。Skill 独立管理项目结构、
`spec_lock`、视觉规划和验收规则；可编辑 PPTX 与插图生成由宿主能力或用户配置的后端完成。

## 最低输入

至少提供实际内容，例如教案、教材、课程大纲、报告、Markdown、DOCX、PDF、已有 PPTX，
或直接粘贴的内容。若有参考模板或用户图片，请上传原始文件；用户提供的图片优先级最高。

## 常用请求

```text
使用 $build-ppt-series，根据上传资料制作一份 20 页技术介绍 PPT。
先规划内容和配图；适合时生成统一风格的插图，不需要为了有图而强行配图。
```

```text
使用 $build-ppt-series，参考我上传的 PPTX 为后续章节制作同系列课件。
提取系列 spec_lock，但每一章重新规划内容、页面节奏和版式映射。
```

```text
使用 $build-ppt-series 优化现有 PPT。页数、顺序和文字保持不变，只改善视觉表达。
```

## 工作方式

1. 检查资料、参考模板、演示文稿后端和图片生成能力。
2. 生成或复用系列级 `spec_lock`，模板冲突交由用户决定。
3. 为当前 PPT 单独生成 `deck_plan` 和 `visual_asset_plan`。
4. 按视觉任务进行一次集中检索，保留少量有效候选图。
5. 制作具体页面时按优先级选图：用户图片、来源/模板图片、可授权外部图片、真实截图、
   原生图表、生成插图、无图。
6. 候选图不合适且确有插图需求时才生成；同一资产最多自动尝试两次。
7. 生成失败则保留简单的 `插图待补充` 占位框和资产编号，继续完成其余页面。
8. 导出后进行结构检查、逐页渲染检查和素材来源检查。

一页可以不需要图片，也可以只使用用户提供的图片。插图风格既要服从统一模板，也要适合
当前场景；若两者冲突，必须暂停该项并让用户决定，不能静默改变模板或替换用户素材。

## 后端说明

- Codex：默认使用宿主 `Presentations`，存在 `imagegen` 时按需生成插图，不需要 PPT Master。
- Claude Code：使用用户配置的原生 PPTX 后端；只有选择本包的 SVG 到可编辑 PPTX 路线时
  才需要 PPT Master 或等价转换器。
- 其他 Agent：可使用经过验证的演示文稿和图片后端。整页栅格化必须获得用户明确同意，
  并报告 `editable: false`。

## 系列结构

```text
<series-root>/
  series/
    spec_lock.md
    template/
    shared-assets/
  decks/<deck-id>/
    spec_lock.md
    sources/
    images/{candidates,sourced,generated}/
    analysis/
      deck_plan.md
      visual_asset_plan.json
      image_briefs/
      generation_records/
    svg_output/
    exports/
```

系列锁只保存跨 PPT 不变量。页数、页面顺序、教学或叙事节奏、具体内容和配图任务都属于
当前 PPT，避免后一份演示文稿成为前一份的换字版本。

## 交付状态

存在未解决占位框时，PPT 只能标记为 `draft/review`。交付报告必须列出对应页码、资产编号、
完整提示词、负面约束、尝试次数和失败原因，并询问用户是否重试或自行提供图片。
